# stouccit

An event-aggregation platform. Discover events around you.

## Teams

- **Data** (`dat-*`, `utils-*`) — ingestion + enrichment pipeline → Postgres. See [Data hub](https://github.com/stouccit/docs/wiki/Data).
- **ML** — model work. See [ML hub](https://github.com/stouccit/docs/wiki/ML) _(stub)_.
- **Frontend** (`app-api`, `app-webapp`, `app-landing`) — web app + landing + backend. See [Frontend hub](https://github.com/stouccit/docs/wiki/Frontend) _(stub)_.

All docs live in **[stouccit/docs/wiki](https://github.com/stouccit/docs/wiki)**.
